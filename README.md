# goit-js-hw-04

JavaScript homework repository for GoIT JS module 4.

## Overview

This project contains exercises and solutions for homework tasks from the GoIT JavaScript module. The project is organized with a simple `index.html` entry point and task-specific JavaScript files in the `js/` folder.

## Files

- `index.html` — project entry point for browser testing.
- `prettierc.json` — Prettier configuration for formatting code.
- `README.md` — project documentation.
- `js/task-1.js` — solution for task 1.
- `js/task-2.js` — solution for task 2.
- `js/task-3.js` — solution for task 3.

## Usage

1. Open `index.html` in a web browser.
2. Review or run the scripts from the `js/` folder.
3. Use the browser console to inspect output and behavior.

## Notes

- The project is intended for learning JavaScript fundamentals.
- Code is organized by homework task.
- Prettier configuration is included to keep formatting consistent.
